ISO 8583 Core Concepts & Spec Reference

1

MTI (Message Type Identifier)

The 4-digit MTI defines the purpose of the message:

  • Pos 1 (Version): 0=1987, 1=1993, 2=2003
  • Pos 2 (Class): 1=Auth, 2=Financial, 4=Reversal, 8=Network
  • Pos 3 (Function): 0=Request, 1=Response, 2=Advice
  • Pos 4 (Originator): 0=Acquirer, 1=Acquirer Repeat, 2=Issuer
2

Bitmaps & Field Flags

The Primary Bitmap (16 hex chars / 64 bits) acts as an index. Bit 1 indicates whether a Secondary Bitmap (bits 65-128) is attached.

Bit 3 = 1 means DE 3 (Processing Code) is included.

3

Data Encodings

  • FIXED: Fixed length string (e.g. DE 3 is 6 digits: 000000).
  • LLVAR: 2-digit length prefix + value (e.g. DE 2 PAN 164532015588991234).
  • LLLVAR: 3-digit length prefix + value (e.g. DE 48 Private Data 012Hello World!).
