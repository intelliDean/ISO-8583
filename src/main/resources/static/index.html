ISO 8583 Core Concepts & Enterprise Spec Reference

A structured reference guide covering the full ISO 8583 payment protocol suite.

1

MTI — Message Type Identifier

The 4-digit MTI defines the purpose, class, function, and originator of a message:

  • Pos 1 (Version): 0=1987, 1=1993, 2=2003
  • Pos 2 (Class): 1=Auth, 2=Financial, 4=Reversal, 8=Network Mgmt
  • Pos 3 (Function): 0=Request, 1=Response, 2=Advice
  • Pos 4 (Originator): 0=Acquirer, 2=Issuer, 4=Other
2

Bitmaps & Field Flags

The Primary Bitmap (16 hex / 64 bits) is a field index. Bit 1 = 1 signals a Secondary Bitmap follows. Each set bit means that data element is present.

7020 → 0111 0000 0010 0000 = DE 2, 3, 4, 11 present

3

Data Encodings

  • FIXED: Exact length (e.g. DE 3 = 6 chars: 000000)
  • LLVAR: 2-digit length prefix + value (DE 2 PAN: 164532015588991234)
  • LLLVAR: 3-digit length prefix + value (DE 48: 012Hello World!)
4

ISO 9564 PIN Block Formats

  • Format 0 (ISO-0): PAN-XOR block — most common in global ATM networks
  • Format 1 (ISO-1): Transaction-independent — no PAN required
  • Format 3 (ISO-3): Enhanced entropy via random padding + PAN XOR
  • Format 4 (ISO-4): 16-byte AES-128 block — chip card transactions
5

ISO 9797-1 Retail MAC

Message Authentication Code using Algorithm 3 (3DES with CBC-MAC). DE 64 holds the 8-byte (16 hex) MAC for 0200 financial requests. DE 128 for secondary MAC.

MAC = 3DES_EDE(KL, KR, CBC_MAC(KL, padded_payload))

6

DUKPT Key Management (ANSI X9.24)

Derived Unique Key Per Transaction — each swipe/dip generates a unique encryption key derived from BDK + KSN. Provides forward secrecy: compromising one key cannot recover past keys.

  • BDK: Base Derivation Key (HSM-injected)
  • KSN: Key Serial Number — 10 bytes (21-bit counter)
  • IPEK: Initial PIN Encryption Key per terminal
7

EMV & BER-TLV (DE 55)

Chip card data is encoded as BER-TLV triplets in DE 55:

  • 9F26 — Application Request Cryptogram (ARQC)
  • 9F36 — Application Transaction Counter (ATC)
  • 9F10 — Issuer Application Data (IAD)
  • 84 — Dedicated File (DF) Name / AID
8

DMS Clearing (1240/1440/1644)

Dual-Message System batch clearing is separate from online authorisation:

  • 1240 — First Presentment (settlement)
  • 1440 — Chargeback (issuer dispute)
  • 1644 — File Header/Trailer (control totals)
  • 1740 — Fee Collection / Interchange Adjustment
